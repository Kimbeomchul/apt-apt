## 공식 기본정보 1차 대조

2026-08-31 버전 [한국부동산원 공동주택 단지 식별정보 기본정보](https://www.data.go.kr/data/15106861/fileData.do)를 다운로드해 단지명·지역·세대수를 대조했다. 공식 파일은 단지고유번호, 주소, 단지명, 단지종류, 세대수, 사용승인일을 제공한다.

| 대조 항목 | 결과 |
|---|---:|
| 공식 파일 전체 행 | 46,385개 |
| 공식 파일 서울·경기 400세대 이상 아파트 | 4,860개 |
| 후보와 이름·세대수가 동시에 일치 | 1,640개 |
| 후보와 이름은 일치하지만 세대수가 다름 | 110개 |
| 생활권 내 퍼지 매칭·세대수 일치(검토 필요) | 1,120개 |
| 생활권 내 퍼지 매칭·세대수 불일치(검토 필요) | 154개 |
| 이름·생활권 매칭 실패 | 1,873개 |

이름 exact 매칭 실패는 표기 변경·공백·브랜드 접두어·통합단지·주소 차이 가능성이 섞인 상태다. 퍼지 매칭 결과도 공식 ID를 확정하지 않고 모두 `needs_review`로 유지한다. 공식 대조 결과는 [Astra 인수인계 문서](./APARTMENT_RESEARCH_HANDOFF.md)의 1단계 작업 입력으로 사용한다.

추출 대상은 상세 페이지 메타 설명이 `서울특별시` 또는 `경기도`로 시작하는 경우로 한정했다. 세대수는 메타 설명의 `세대수 N세대` 값을 정수로 읽어 400 이상만 남겼다. 준공연도가 없는 페이지는 `미확인`으로 보존했다.

## 출처와 한계

- 원문 인벤토리: [아구구 단지 sitemap](https://a99.co.kr/apt/sitemap.xml) 및 각 단지 상세 페이지
- 세대수 교차검증 대상: [K-apt 공동주택관리정보시스템](https://www.k-apt.go.kr/web/main/index.do)
- 공식 단지 마스터 교차검증 대상: [한국부동산원 공동주택 단지 식별정보](https://www.data.go.kr/data/15106861/fileData.do)
- 거래 교차검증 대상: [국토교통부 아파트 매매 실거래가 API](https://www.data.go.kr/data/15126468/openapi.do)

이 감사는 sitemap에 포함된 후보를 빠짐없이 읽었다는 뜻이지, 국내 공식 전수 단지 마스터와 일치한다는 뜻은 아니다. 공식 ID·주소 매칭 전에는 통합단지, 주상복합, 임대·분양 혼합, 단지명 변경, 누락된 단지를 확정할 수 없다.
