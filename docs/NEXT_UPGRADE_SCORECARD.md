# 추가 고도화 우선순위 계산표

작성일: 2026-09-18. 평가 기준은 현재 서비스의 구매 가능성 계산·단지 비교 흐름이다.

점수는 `사용자 가치 40 + 재사용성 20 + 데이터 실행 가능성 20 + 신뢰 개선 20 - 구현 비용 0~20 - 데이터 위험 0~20`으로 계산했다. 80점 이상은 다음 릴리스, 60~79점은 검증 후, 59점 이하는 보류로 분류한다. 정량 사용성 실험 전의 기획 점수이므로 시장 성과 예측이 아니다.

## P0: 계약 전 점검 리포트

현재 서비스는 구매 가능 금액을 계산하지만 계약 직전의 실수를 줄이는 단계가 비어 있다. 선택 단지에 대해 `가격 기준일·표본 수`, `정책 확인일`, `최근 고액 신용대출 상태`, `보증금 반환일`, `증여세 반영 여부`, `계약금·중도금·잔금 자금 부족`을 한 장으로 묶는다.

완료 기준:

- 사용자가 `확인됨 / 사용자 확인 필요 / 자료 없음`을 구분한다.
- 금융기관 승인·법률 검토가 필요한 항목에는 확인할 기관과 행동을 표시한다.
- 인쇄/PDF 보고서에서 계산 입력과 자료 기준일을 함께 보존한다.
- 금융정보를 URL·분석 로그·서버에 포함하지 않는다.

## P1: 관리비·장기수선 비교

한국부동산원 K-apt는 100세대 이상 공동주택의 관리비 공개 의무와 단지별 관리비·관리시설·장기수선계획·회계감사 정보를 제공한다. [K-apt 공식 안내](https://www.k-apt.go.kr/web/main/index.do)와 [한국부동산원 설명](https://www.reb.or.kr/reb/cm/cntnts/cntntsView.do?cntntsId=1204)을 근거로, 가격만으로는 보이지 않는 월 주거비를 비교한다.

첫 버전은 평균 관리비를 구매 가능성 계산에 자동 합산하지 않는다. `최근 공개월`, `전용면적당 공용관리비`, `장기수선충당금`, `공개 지연 여부`를 별도 패널로 제공하고 출처·기준월을 표시한다. 단지 식별자 매칭과 API 이용 조건을 먼저 검증한다.

## P1 검증: 전월세·보증금 시나리오

매매만 보는 이용자도 현재 전세·월세 계약과 보증금 반환 시점을 함께 고려한다. 매매 계산과 섞지 말고 `보증금 반환 전 / 반환 확정 / 반환 지연` 세 상태를 비교한다. 국토교통부 실거래 데이터의 전월세 구분과 출처를 확인한 뒤 추가한다.

## 데이터 확인 후: 출퇴근·학교

서울 열린데이터광장 교통 API는 인증키가 필요하고 실시간 지하철 API는 하루 1,000건 요청 제한이 안내되어 있다. [서울시 Open API 이용안내](https://data.seoul.go.kr/together/guide/useGuide.do)와 [TOPIS API 안내](https://topis.seoul.go.kr/refRoom/openRefRoom_4.do)를 먼저 확인한다. 학교알리미도 인증키·이용 제한이 있으며, [학교알리미 API 안내](https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_m0.do)는 최근 3년 공시 범위를 안내한다.

따라서 첫 단계는 지도 위 점수화가 아니라 목적지 주소를 외부 길찾기로 넘기고, 학교는 학교명·주소·공시 기준일을 보여주는 수준으로 한다. 좌표 매칭·호출량·상업 이용 조건이 확인된 뒤에만 거리나 소요시간을 후보 점수에 넣는다.

## P2: 변경 알림

로그인 없는 브라우저 저장으로 관심 단지의 마지막 확인일·가격·표본 수를 보관하고 다음 방문 때 달라진 항목을 표시한다. 서버 푸시와 이메일은 계정·동의·보안 운영이 필요하므로 후순위다.

## 보류: 자연어·AI·미래가격

자연어는 기존 필터를 채우는 보조 입력으로는 유용하지만, 현재 데이터 범위와 기준일을 벗어난 추천을 만들 위험이 있다. 미래가격·투자등급은 검증 데이터와 책임 범위가 부족해 추가하지 않는다.

## 추천 순서

1. 계약 전 점검 리포트와 현재 PDF를 연결한다.
2. K-apt 매칭 파일·API 권한을 확인한 뒤 관리비 패널을 만든다.
3. 전월세·보증금 상태를 매매 자금 일정표와 분리해 검증한다.
4. 교통·학교는 인증키와 호출 제한을 확인한 뒤 목적지 링크부터 제공한다.
5. 변경 알림과 자연어 검색은 실제 사용성 데이터를 확인한 뒤 결정한다.
