# 부부 합산·현금 증여세·신용대출 상태

구현·근거 확인일: 2026-09-17. 공개 사이트 미배포.

## 신용대출

기존 `creditRestriction` 불리언은 전액 상환 여부를 구별하지 못했다. UI는 `creditStatus`의 none / active / repaid / unknown으로 교체했다. 기존 테스트·외부 프로필의 불리언은 보수적으로 active에 대응한다.

- active / unknown: 규제지역 가정에서 예산 계산 보류. 구매 불가로 단정하지 않는다.
- repaid: 전액 상환·한도 해지 및 제한 종료를 가정한 조건부 참고 계산. 상환 이력만으로 차단하지 않는다. 다른 남은 부채는 자동 삭제하지 않는다.
- 계산 보류 상태에서 ‘예산 안’ 필터가 켜져 있으면 해당 필터만 일시 보류하고, 나머지 조건의 목록을 표시한다. 보류 사유와 복원 동작을 안내한다.
- 부부 합산에서는 두 사람 상태를 함께 반영한다. active / unknown은 보류, repaid는 조건부 안내를 유지한다.

실행일부터 1년 또는 전액 상환일 중 빠른 날까지 제한하는 [우리금융캐피탈 약정 사례](https://www.woorifcapital.com/loan/popUp/xsellLoanInfo.do)와 [KB 제휴 대환 신용대출 제6조](https://img2.kbstar.com/obj/ocommon/0322contract01.pdf)를 확인했다. 모든 금융사 약정에 동일하게 적용한다고 주장하지 않는다. 마이너스통장의 잔액 0과 한도 해지는 구별하고, 이전 위반·추가 약정·구입일 판정은 금융사 확인이 필요하다.

## 부부 합산

‘나 혼자 / 부부 합산’ 버튼으로 전환한다. 본인·배우자의 세전 소득, 현금, 월 실수령, 기존 부채 잔액, 규정상 연 원리금, 실제 월 납입액을 각각 받는다. 배우자 값은 단독 모드에서 제외하되 탭을 오갈 때 보존한다. 초기화는 단독 기본값으로 돌아간다.

금융위의 [배우자 소득·부채 합산 허용 근거](https://www.fsc.go.kr/po010106/78134)를 참고했다. 공동차주 등 상품별 합산 심사 가능성을 가정한 예산이며 한도는 주택당 한 번 적용한다. 소득만 합산하고 배우자 부채를 누락하지 않도록 사람별 정합성을 검증한다. 주택 보유·과거 보유는 세대 기준이며 생활비·보증금·비상금은 가구 합계로 한 번 입력한다. 공동명의 지분·자금출처에 대한 세금은 별도다.

## 증여세 계산 범위

성년 국내 거주자의 일반 현금 증여를 본인·배우자 각 1개 증여자 그룹에 대해 계산한다. 자료: [국세청 항목별 설명](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7960&mi=6533), [혼인·출산 공제 안내](https://www.nts.go.kr/webtv/na/ntt/selectNttList.do?bbsId=30148&mi=10675&nttSn=1335073).

- 기본 공제: 부모·자녀 5천만원, 법률상 배우자 6억원, 공제 대상 기타 친족 1천만원, 그 외 0. 공제 사용 이력을 반영한다.
- 부모의 배우자는 동일인으로 합산하며, 같은 관계 구분의 다른 증여자에게 쓴 공제와 동일인 과거 공제액을 별도 입력한다. 합산대상 이전 증여액 1천만원 이상이면 과거 과세표준을 더한다.
- 10~50% 5단계 누진세율, 과세표준 50만원 미만 과세최저한, 과거 산출세액 공제의 비례한도, 기한 내 신고 가정 시 3% 신고공제를 반영한다.
- 혼인·출산 추가공제는 사용자가 요건을 확인한 부모 증여에 한해 수증자별 통합 1억원에서 기사용액을 뺀 금액까지 적용. 날짜·서류 적격 자동판정은 하지 않는다.
- 증여금에서 세금을 미리 차감한 순액만 현금에 더한다. 이미 증여받은 돈을 입력하는 경우 기존 현금에서 빼고 이 항목에 분리해야 한다. 부부간 내부 증여는 가구 현금을 늘리지 않고 세금만 차감하며 증여자 현금 한도를 검증한다.
- 미성년·비거주자·조부모 세대생략·부동산/주식·특례·다수 그룹 동시 증여는 지원 범위 밖. ‘별도 검토’ 선택은 0원 세금으로 처리하지 않고 계산을 보류한다. 증여자의 세금 대납, 가산세, 과거 신고의 특수한 세액공제, 지방세·취득세는 포함하지 않는다.
- 현금·소득·증여 입력은 메모리에만 보관한다. 유효하지 않은 입력 시 이전 예산을 남겨두지 않고 보류한다.

## 검증

Node 36개 통과: 세율 경계, 과세최저한, 관계 공제, 혼인·출산 한도, 과거 증여 합산, 과거 납부세액 공제, 부부 부채 합산과 한도, 내부 증여 중복 방지, 상환·미확인 상태, 단독 전환.
