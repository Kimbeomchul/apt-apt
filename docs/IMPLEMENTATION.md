# 구현 상태 · 2026-09-16

## 동작하는 기능

- 독립 실행 가능한 반응형 웹사이트. GitHub Pages 하위 경로 동작 확인.
- 초기 7개 단지의 실명·세대수·준공연도·참고가격·날짜·출처.
- 지역·평형·검색·정렬·예산 필터, 관심 단지 브라우저 저장, 최대 3개 비교.
- 주소를 포함한 네이버 매물 검색 연결. 세종주공6단지는 확인된 네이버 단지 ID로 직접 연결.
- 일반 무주택자 시나리오의 LTV·DSR·절대한도, 비용·비상금·생활비·기존대출·순보증금 반영.
- 안정·최대 구매 예산, 개별 매물 가격 수정, 월 상환·현금 부족·금리 및 소득 충격 계산.
- 데이터·평가·정책·개인정보 설명 화면.
- 표준 CSV 가져오기와 국토부 상세 실거래 API 수집기. API 키가 없으므로 실 API 연동 실행은 미검증.
- main push/수동 실행/매일 예약에 사용하는 단일 GitHub Actions 테스트·수집·배포 워크플로.

## 원래 기획과 차이

- React 대신 외부 패키지 설치 없이 실행되는 ES modules를 사용. 정적 Pages 배포 목표는 유지.
- 전체 서울·경기 단지 마스터와 API 승인이 아직 없어 초기 7개 조사 단지만 제공.
- 입지·단지 품질·커뮤니티 정보를 검증하기 전에는 입지 급지나 점수를 발행하지 않음. 현재 가격군은 선택 평형의 고정 금액 구간이며 급지와 구별.
- 지도·출퇴근 경로 계산·검증된 학군 정보·정책대출 특례·로그인·직접 후기 작성은 미구현.
- 정책 근거에 2026-06-30 동탄구·기흥구·구리시 추가 지정 자료를 보강. 전체 현행 규정 검증 완료라고 주장하지 않음.
- 화면 가격은 제3자 공개 페이지에서 확인한 거래 참고자료. 공식 API 수집 후 취소 여부·동일 단지·면적을 재검증해야 함.

## 검증

- Node 단위 테스트 19개 통과: 대출 계산·비용·15억/25억 경계·부채·보증금·데이터 범위.
- Python 테스트 7개 통과: 해제/직거래·중복·기간·중위값·면적·세대수·월 변경.
- Chrome 실제 브라우저 검사 통과: 데이터 로딩, 지역/검색/평형, 상세 계산, 비교, 관심, 예산 필터, 모바일 오버플로, dist 하위 경로, 브라우저 예외 없음.
- 1440px 데스크톱 / 390px 모바일 스크린샷 육안 확인. 스크린샷은 `artifacts/`에 있으며 Git에는 제외.
