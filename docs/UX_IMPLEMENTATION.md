# 2026-09-18 UX 개선 구현 기록

## 반영한 동작

- 탐색이 기본 진입이다. 자금 설정 없이 4,860개 마스터의 검색·가격대·단지 상세·관심·비교를 이용한다. 예시 금융값으로 개인화 결과를 미리 표시하지 않는다.
- 자금 입력은 별도 모달에서 진행한다. 입력 중에는 초안의 증여 계산·자금 요약만 갱신하고 목록·적용 예산은 유지한다. 결과 적용 시 검증하며 닫기·Escape·브라우저 뒤로 가기는 변경 전 값으로 복원한다.
- 부부 전환 시 배우자 입력을 유지하고 포함 여부만 바꾼다. 증여는 선택해서 펼치며 금액 필드에 억/만원 읽기 보조를 제공한다. 기존 증여세·대출 규정 계산식은 유지했다.
- 자금 미설정·약정 확인 필요 시 예산 필터로 전체 목록을 없애지 않는다. 0건에는 활성 조건을 표시하고 개별 조건 해제·전체 초기화·예산 필터 해제를 제공한다. 원인별 제외 개수 분석은 아직 없다.
- 주요 검색은 지역·면적·가격대로 정리하고 상세 조건은 접는다. 카드는 선택 면적의 가격과 기준일·표본 수를 중심으로 표시한다. 반복되는 기술 설명과 가격군 배지는 제거했다.
- 안정 예산을 우선 표시하고 최대 예산·계산 근거는 펼쳐 본다. 모바일 자금 입력과 단지 상세는 화면 전체를 사용하고 확대·좁은 화면에서도 넘침을 방지한다.
- 최근 검색 조건·목록 페이지·비교 후보를 복원한다. 관심 단지는 기존 저장을 유지한다. 자금 조건은 사용자가 ‘이 기기에 저장’을 선택한 경우에만 localStorage에 보관하며 개인정보 화면에서 삭제한다. 공유 링크에 자금 값은 포함하지 않는다.
- 상세의 가격·거래 / 내 자금 / 단지 정보 이동을 제공한다. 뒤로 가기로 상세를 닫고 기존 목록 위치로 돌아온다.
- 비교 보고서는 최대 3개 단지의 가격·집계 기간·표본·부족 자금·상환액을 제공한다. 단지별 집계 기간이 다를 수 있음을 표시한다. 단지 상세와 비교 모두 브라우저 인쇄/PDF 저장을 지원한다.
- 금리 +0~3%p, 월 실수령 0~−30% 변화에 따른 잔여 현금흐름을 비교한다. 원금은 고정하며 금융기관 한도를 다시 판정하는 계산이 아니다.
- `내 조건 추천순`은 가격 자료가 있는 후보의 예산 상태·거래 표본·월 부담을 함께 반영한다. 점수는 입지나 투자 등급이 아니며, 카드에 추천 이유를 함께 보여준다.
- 0건 결과는 현재 조건을 유지한 채 예산·가격대·시군구·지역·관심 필터를 하나씩 완화했을 때의 후보 수를 계산해 버튼으로 제안한다. 사용자가 누른 조건만 변경한다.
- 단지 상세의 부족 자금 시뮬레이터에서 추가 현금과 집값 인하율을 조합해 부족액·월 상환액 변화를 확인한다. 실제 금융기관 승인 예측은 아니다.
- 자금 설정 창에서 최대 5개 조건을 기기에 저장하고, 불러오기·삭제·안정/최대 예산 나란히 비교를 제공한다. 저장은 사용자가 버튼을 누른 경우에만 수행한다.
- 계약금·중도금·잔금 날짜와 비율, 현재 가용 현금, 외부 자금·보증금의 수령일을 입력하는 일정표를 추가했다. 주담대는 잔금일에만 반영한다. 최종 자금이 충분해도 앞선 시점의 부족은 따로 표시한다.

## 검증

- `npm run check`: Node 46개 테스트, 문법 검사, 4,860개 데이터 검증과 정적 빌드 통과.
- `python -m unittest discover -s tests -p 'test_*.py'`: 13개 통과.
- `node scripts/browser-smoke.mjs http://127.0.0.1:4173/dist/`: 실제 Chrome에서 빌드 경로 검증 통과. 기존 진입점은 새 `browser-ux.mjs`를 호출한다.
- 브라우저 검증 범위: 전체 목록·끝 페이지·시군구·자료 필터·공유 복원·기간별 통계, 초안/적용/취소·뒤로 가기, 부부/증여/신용 상태, 저장 및 삭제, 관심·3개 비교 한도, 자금 일정 오류·부족, 금리 민감도, PDF 생성.
- 320/390/768/1440px 목록·상세와 360/390/768/1440px 확장 입력, 200% 확대에서 가로 넘침 검사. 390×844 첫 후보 시작 위치는 약 616px로 하단 고정 메뉴 위에 노출된다. 이는 자동 캡처 결과이며 사용자 과제 성공률이 아니다.
- 로컬 산출물: `artifacts/ux-mobile.png`, `artifacts/ux-desktop.png`, `artifacts/ux-comparison.pdf` (배포에는 포함하지 않음).

## 남은 장기 작업과 범위

- 실수요자 5~8명 과제 테스트·인터뷰·개선율 측정은 실제 참여자가 필요하므로 수행하지 않았다. 자동 UI 검증으로 대체 완료 처리하지 않는다.
- 공식 API 최신 수집, 정정 거래 자동 반영, 지도·생활권 정보, 정책 상품 확대는 유효한 데이터 연결·권한·공식 조건 검증이 필요하다. 현재 데이터 기준일은 2026-09-16이며 이번 배포가 가격 갱신을 뜻하지 않는다. 기존 스케줄 빌드만으로 신규 원자료가 자동 확보되는 것도 아니다.
- 일정표의 날짜와 비율은 예시이며 사용자 입력으로만 검증한다. 보증금·증여의 실제 입금, 은행 실행 확약, 계약 조건을 자동 확인하지 않는다. 수령한 돈과 앞으로 받을 돈은 사용자가 중복 없이 구분한다.
- PDF는 브라우저 인쇄 기능이다. 원클릭 서버 PDF 생성이나 저장 프로필의 기기 간 동기화는 포함하지 않는다.

금융정보를 외부에 전송하는 분석 도구나 로그인을 추가하지 않았다.
