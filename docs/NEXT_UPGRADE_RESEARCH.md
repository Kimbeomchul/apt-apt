# 다음 고도화 조사 결과

작성일: 2026-09-18. 현재 배포 버전 `a872b0c` 기준.

## 조사에서 확인한 시장 방향

- [네이버페이 부동산](https://land.naver.com/)은 지역·단지 검색과 매물지도를 핵심 진입점으로 두고, 최근 검색·MY·우리집 흐름을 제공한다. 이 서비스는 매물 탐색에 강하므로 우리 서비스가 매물 수로 경쟁할 이유는 약하다.
- [KB부동산의 공식 시세 간편조회](https://kbland.kr/main/quickPriceSearch)는 지역·단지·평형으로 KB(AI)시세가 있는 단지를 조회한다. [KB의 AI 단지분석 발표](https://omoney.kbstar.com/quics?articleClass=&articleId=145046&bbsMode=view&boardId=647&compId=b031438&page=C017648&searchCondition=title&searchStr=&viewPage=1)는 시세뿐 아니라 학군·교통·개발 호재를 종합 분석한다고 설명한다.
- [호갱노노 공식 앱 소개](https://play.google.com/store/apps/details?hl=ko&id=com.hogangnono.hogangnono)는 실거래가·시세·단지 정보·입주민 이야기와 대화형 추천을 한 흐름으로 묶는다.

해석: 시장의 기본 기대치는 `검색 → 단지 정보 → 비교`를 넘어서 `생활 조건과 미래 변화까지 한 화면에서 판단`하는 수준으로 올라가고 있다. 하지만 우리 서비스가 아직 검증하지 않은 교통·학군·개발 데이터를 점수화하면 설명 가능성과 정확성을 잃는다. 다음 단계는 AI나 점수보다 **공식 근거가 있는 생활 조건과 구매 가능성의 연결**이어야 한다.

## 우선 구현할 것

### P0 — 구매 의사결정 완성도

1. **구매 가능성 설명 카드**
   - `가능`, `조건부`, `추가 자금 필요`, `자료 확인 필요`를 구분한다.
   - 각 상태에 원인을 하나씩 표시한다. 예: `DSR 한도`, `담보비율`, `정책 상한`, `초기 현금`, `월 상환 여력`.
   - 사용자가 원인을 누르면 실제 입력값·계산 근거·바꿀 수 있는 입력으로 이동한다.
   - 목표: “왜 이 집이 안 되는지”를 결과만 보고 설명할 수 있게 한다.

2. **구매 가능 가격선 차트**
   - 집값을 가로축으로 두고 안정 예산·최대 예산·추가 자금 필요 구간을 표시한다.
   - 15억·25억 정책 상한이 꺾이는 구간을 표시한다.
   - 현재 가격과 후보 가격을 선 위에 표시한다.
   - 목표: 여러 후보를 열어 보지 않아도 내 예산의 경계를 이해하게 한다.

3. **자료 신뢰도 패널**
   - 대표가격의 기준일, 거래 기간, 표본 수, 가격 미확인 사유를 카드 상단에 노출한다.
   - 신뢰도라는 종합 점수는 만들지 않고, `최근·5건 이상`, `소표본`, `오래된 자료`, `미확인` 같은 근거 라벨을 사용한다.
   - 목표: 거래가 적은 단지를 확정 가격으로 오해하지 않게 한다.

### P1 — 생활 조건 연결

4. **출퇴근 목적지 입력**
   - 사용자가 직장·학교 주소를 입력하면 지도 API 또는 외부 길찾기 링크로 이동한다.
   - 첫 버전은 통근 시간을 내부 점수로 합산하지 않고, 후보별 `확인할 링크`로 제공한다.
   - 좌표·API 이용 조건이 확인되면 평일 시간대별 소요시간을 추가한다.

5. **생활 체크리스트 저장**
   - 단지별 주차, 소음, 통학, 역 거리, 수리비, 일조, 관리비를 사용자가 직접 체크하고 메모한다.
   - 자동 점수 대신 사용자의 가중치와 메모를 비교 화면에 보여준다.
   - 목표: 가격 계산기에서 실제 임장 의사결정 도구로 확장한다.

6. **후보 변경 알림의 기초**
   - 로그인 없이 이 기기에서 관심 단지의 마지막 가격·기준일을 저장한다.
   - 다음 방문 시 가격·표본·자료 기준일 변경을 알려준다.
   - 서버 푸시 알림은 계정·동의·운영비가 필요하므로 나중에 한다.

### P2 — 데이터·검색 확장

7. **거래 가격과 현재 호가 분리**
   - 매물 데이터 연동이 허용되고 출처·갱신 주기가 확인될 때만 추가한다.
   - 실거래 중위값과 현재 호가를 같은 가격으로 묶지 않는다.

8. **자연어 검색 보조**
   - `8억 이하, 판교 출퇴근, 84㎡`를 기존 필터로 변환하는 보조 기능부터 시작한다.
   - 금융·소득 입력은 외부 AI로 전송하지 않는다.
   - AI 답변은 반드시 사용한 단지·필터·자료 기준일을 표시하며, 근거 없는 추천 문장을 만들지 않는다.

9. **정책 버전 비교와 변경 알림**
   - 현재 계산 버전과 이전 버전의 LTV·DSR·가격 상한 차이를 보여준다.
   - 정책 원문이 갱신되지 않은 경우 계산 결과를 최신으로 표시하지 않는다.

## 지금 하지 않을 것

- 근거가 부족한 입지 종합점수·투자등급
- 로그인 강제와 금융정보 서버 저장
- 검증되지 않은 AI 미래 가격 예측
- 자체 매물·지도 서비스를 데이터 권한 확인 전에 추가
- 체류시간이나 클릭 수를 높이기 위한 추천 배지 남발

## 측정할 지표

- 후보 상세까지 걸린 시간
- 구매 가능성 원인을 맞게 설명한 비율
- 0건 대안 버튼을 눌러 후보를 찾은 비율
- 시나리오 저장 후 비교까지 완료한 비율
- 자료 기준일·표본 수를 확인한 비율
- 생활 체크리스트를 작성한 후보의 비교 완료율

체류시간, 페이지뷰, AI 호출 수는 품질 지표로 사용하지 않는다. 금융 입력값·직장 주소·메모를 분석 로그에 원문으로 저장하지 않는다.

## 추천 실행 묶음

첫 구현은 `구매 가능성 설명 카드 + 구매 가능 가격선 차트 + 자료 신뢰도 패널`로 한다. 기존 계산 엔진과 거래 데이터만 사용하므로 외부 연동 없이 검증할 수 있고, 현재 사용자의 가장 큰 질문인 “이 아파트가 왜 가능한가/불가능한가”에 바로 답한다.

그 다음 `출퇴근 목적지 + 생활 체크리스트`를 붙인다. 이 단계부터는 지도·학교·교통 데이터의 출처와 호출 한도를 먼저 확정한다. 자연어 검색과 AI 단지 분석은 이 두 단계의 데이터 품질이 확인된 뒤 진행한다.
